Simple Shooting Game
作品説明書・簡易仕様書

1. 作品概要
────────────────────────────────────────
C# と Windows Forms で制作した、2Dシューティングゲームです。
自機を左右に動かして弾を発射し、画面上部から降りてくる敵を倒して
スコアを獲得します。ゲームオーバー後は再開できます。

2. 使用技術・実行環境
────────────────────────────────────────
・使用言語：C#
・画面の作成：Windows Forms
・開発ツール：Visual Studio（.NET 10 と .slnx に対応する環境）
・実行対象：Windows

対象フレームワーク：.NET 10（net10.0-windows）
同梱のプロジェクトファイル（.csproj）の
TargetFramework に設定されています。
Visual Studio には「.NET デスクトップ開発」の環境と、プロジェクトに
対応する SDK／ターゲットパックが必要です。

3. 起動方法
────────────────────────────────────────
本資料は、ソースコード一式を提出する場合の説明です。

① ZIPファイルを任意のフォルダーにすべて展開します。
② 展開先のソリューションファイル（SimpleShootingGame.slnx）をVisual Studioで開きます。
   .slnx を開けない場合は、SimpleShootingGame.csproj を開いてください。
③ 必要な開発環境がインストールされていることを確認します。
④ F5キー、またはVisual Studioの「開始」を押して実行します。
⑤ ゲーム画面の「START」を押してプレイします。

※ZIP内のファイルを直接開くのではなく、先に全体を展開してください。
※Form1.csだけでは起動できません。デザイナーやプロジェクトの設定など、
  同梱のファイル一式を使用してください。

4. 操作方法
────────────────────────────────────────
・STARTボタン      ：ゲーム開始
・左矢印キー（←）  ：左へ移動
・右矢印キー（→）  ：右へ移動
・スペースキー     ：弾を発射。押し続けると一定間隔で連射
・RESTARTボタン    ：ゲームオーバー後、初期状態から再開

左右キーを同時に押した場合、自機は横移動しません。

5. ゲームのルール
────────────────────────────────────────
・自機は画面下部から開始し、左右に移動します。
・敵は画面上部のランダムな横位置から出現し、下へ移動します。
・弾が敵に当たると、弾と敵が消え、100点加算されます。
・敵が画面下へ完全に抜けると、100点減点されます。
・スコアには下限がなく、0点未満になる場合があります。
・敵が自機に接触すると「GAME OVER」を表示してゲームが停止します。
・再開すると、弾・敵・得点・入力状態・待ち時間を初期化します。
・クリア条件や制限時間は設けていません。

6. 実装した主な機能
────────────────────────────────────────
【入力と移動】
キーの押下・解放を記録し、タイマー更新時に自機を移動させます。
自機の横位置は画面端の範囲に制限します。

【射撃】
スペースキーを押している間、待ち時間を確認して弾を発射します。
画面上へ完全に抜けた弾は削除します。

【敵の生成】
開始時に1体を生成し、その後は一定の更新回数ごとに追加します。
出現位置は乱数を使って決定します。

【当たり判定】
PictureBoxの矩形領域（Bounds）の重なりを使い、弾と敵、敵と自機の
接触を判定します。

【スコアと再開】
得点の変化を画面に反映します。開始と再開は共通の処理を使用します。

【オブジェクト管理】
弾と敵をそれぞれリストで管理します。削除時はリストと画面から外し、
Disposeでコントロールのリソースを解放します。

7. ゲーム内の設定値
────────────────────────────────────────
・自機の移動量：1回の更新あたり10ピクセル
・弾の移動量  ：1回の更新あたり上へ10ピクセル
・敵の移動量  ：1回の更新あたり下へ3ピクセル
・射撃間隔    ：12回のタイマー更新
・敵の出現間隔：60回のタイマー更新
・敵の大きさ  ：40×40ピクセル
・弾の大きさ  ：5×15ピクセル

これらの間隔は秒数ではありません。実際の速度や時間はtimer1.Interval
の設定と画面処理の負荷に依存します。

8. 制作・コード整理について
────────────────────────────────────────
制作したゲームコードをもとに、AIの支援を利用してコードを整理しました。
支援を受けた内容には、開始・再開処理の共通化、タイマー処理の分割、
画面端の移動制限などの修正、解説コメントと本説明書の作成が含まれます。

コードは、移動・射撃・敵の生成・当たり判定・スコア更新などの役割ごとに
メソッドを分けています。開始と再開、弾と敵の削除といった共通処理を
まとめ、修正箇所が分散しない構成にしています。

9. 動作確認と現在の仕様上の制限
────────────────────────────────────────
【実施済みの確認】
・制作者の環境で、ZIPを別の場所へ展開した状態から起動・実行できる
  ことを確認しています。

【現在の仕様上の制限】
・別のウィンドウに切り替えるとキーの押下状態は解除しますが、ゲームは
  自動で一時停止しません。
・当たり判定は矩形同士で行い、画像の透明部分などは考慮しません。
・スコアはゲーム中のみ保持し、再開時に0へ戻します。
・他のPCや異なる開発環境での動作確認結果は、本資料には含みません。

※本資料は、コード整理後のForm1.csの内容に基づいています。
  提出用プロジェクトを変更した場合は、対応する説明も更新してください。

# Simple Shooting Game

C# / Windows Formsで制作した2Dシューティングゲームです。左右移動と連射で敵を倒し、スコアを獲得します。

## 主な機能

- キーの押下・解放による移動と連射
- 敵のランダム配置と一定間隔での生成
- 矩形の重なりによる当たり判定
- スコア表示、ゲームオーバー、再開
- 弾・敵のリスト管理と削除時のリソース解放

## 起動

Windowsと.NET 10 SDK、Windows Formsの開発環境が必要です。

1. リポジトリを取得して展開します。
2. Visual Studioで`SimpleShootingGame.csproj`を開きます（対応環境では`.slnx`も使用できます）。
3. ビルド・実行し、画面の「START」を押します。

このリポジトリはソースコード一式です。実行用exeは同梱していません。

## 操作

| 入力 | 動作 |
|---|---|
| 左右矢印キー | 自機の移動 |
| スペース長押し | 連射 |
| START / RESTART | 開始 / 再開 |

## コードの入口

- [Form1.cs](Form1.cs)：入力、タイマー更新、移動、射撃、生成、当たり判定、再開処理。
- [Form1.Designer.cs](Form1.Designer.cs)：画面のコントロール配置とイベント接続。
- [Program.cs](Program.cs)：アプリケーションの起動。
